# 阶段 08：S2 共享子集、空间表示与模型实现

S2 已冻结 **80,000 train + 10,000 validation** 的共享子集，完成新表示和 ParticleNet/geometry-adapted ParT 实现。四项针对新实现的测试及 32-event ROOT 转换、真实原生输入 CPU forward/backward 已通过。S2 的批量训练与物理比较尚未完成；本报告记录进入批量作业前的实现与实际验证。

## 阶段目标

建立可分开量化 pixel 粒度、联合位置/投影关联和模型结构的公共数据与运行接口。沿用用户接受的 S0/S1 manifest 和 detector-proxy，不重查生产认证或真实硬件标定。

## 工作内容

- 新增 `analysis.flavour.s2.prepare`。每类用 seed 42 从可用 chunks 不放回抽取 32 个，再从既有 train split 选 20,000 行、validation 选 2,500 行。全部表示与模型复用 `manifest.parquet`，不重新随机分配 split，不按 occupancy 删除事件。每个输出 shard 混合四类，按固定随机序列排列；批量任务一次处理两个 shard，共 16 tasks。
- 定义 S2 pixel-centered：ROOT pixel 边界内缩 20 mm，target 最前 500 mm；large-scintillator：bar 几何边界内缩 15 mm、target 下游内缩 200 mm。target 起止取 tungsten 极端中心加减半厚度，为 `[-2993.0, -1804.88] mm`。这些是本阶段明确的条件诊断定义，不声称与历史未给全配置的图完全相同；主训练仍用完整选定目标域。
- 新增 `representation.py`：native/100 μm/200 μm/1 mm joint cell，以及 native/1 mm 的 xz/yz sparse marginals。count 保留激活原生 pixel 数；OR 只保留占用。粗表示不带原生 cell 内位置残差，投影不带 x–y pairing，未测坐标有 validity。返回原生 channel→表示 token 映射供 toy 与信息损失诊断使用。
- 两个模型族使用相同的局部划分：pixel plane 内 4 mm cell，bar panel，tracker station 与 16 mm 区域；超过 32 nodes 的块按当前可测几何排序后拆分。全部点先经 learned local encoder，再池化每块，全部块进入全局编码；不限制事件 token 数。这个公共局部压缩是本次 baseline 的明确组成部分，不称为未经压缩的全事件 global attention。18 列 observation 特征包含固定物理尺度绝对位置、当前表示的局部位置残差、可测坐标 mask、count/信号、区间/误差、detector type 与 response；不传 truth/provenance。
- ParticleNet adaptation 使用 3 local + 3 global EdgeConv blocks，k=16，首个全局几何图分配同 plane 与跨 plane 邻居 quota，后续采用动态 feature graph。ParT adaptation 使用 2 local + 4 global attention blocks，4 heads，加测量几何 pair bias，预留 vanilla/no-pair 对照。两者均用 detector-wise mean/max pooling 与四类头。
- `s2.dataset` 从 worker 私有 scratch 的 native shard 派生表示，窗口内混类抽样。`s2.train` 仅使用 train/validation，以 validation NLL 选 best，保存 best/last、每行四类概率、软件/配置/资源/时长。支持固定 physical normalization、class weights、AdamW、mixed precision、完整局部块 gradient checkpointing。
- τ 分道仅从 `primaries` 的 primary τ track ID 和 `tau` 的直接 parent ID/PDG 对应，避免 `trackID==1` 或“事件里出现任意 lepton”的定义。只保存为诊断 metadata，不作为输入。找不到完整 direct decay 时保留 unknown。

## 阶段性结论

**事实：**固定子集和完整通道表示已实现，小样本可完成转换及两个模型族的 CPU 优化梯度计算。toy 测试能直接展示 projection 移除 joint pairing、coarse cell 移除内部细节。新模型性能、统计增益和最优资源配置目前未测量。

**研究假设：**公共局部 learned encoder 先保留当前表示内部布局，再比较两种全局关系机制，能够让粒度/投影对照在相同模型族中成立。local block pooling 的压缩和边界效应需通过后续 toy、局部重建/遮挡与分类消融测量；不能把其资源优势当成分类收益。
